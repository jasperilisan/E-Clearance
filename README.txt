E-CLEARANCE FRONT-END DEMO
==========================

Pages
- index.php       : Login page
- register.php    : Create account page
- dashboard.php   : Student dashboard / clearance tracking prototype
- assets/css/style.css
- assets/js/app.js

How to run with XAMPP
1. Copy the folder "eclearance_frontend" into C:\xampp\htdocs\
2. Start Apache from the XAMPP Control Panel.
3. Open your browser and visit:
   http://localhost/eclearance_frontend/

Important
- This is FRONT-END ONLY.
- Login and registration do not save or verify accounts in a database.
- Forms redirect to the dashboard to demonstrate the user experience.
- Dashboard data is sample/demo data and can be replaced later with PHP/MySQL data.
